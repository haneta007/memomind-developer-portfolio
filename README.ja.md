# 個人開発ポートフォリオ

Kotlin と C# を使い、Android・Windows 向けのアプリを個人開発しています。AI 支援付きのインボックスを持つランチャー、PC とスマートフォンをまたぐレビュー支援、E Ink 端末で読む・書くためのツールを開発してきました。開発には AI 支援ツールも使い、実現したい振る舞いに照らして変更を確認しています。

| プロジェクト | 主な機能 |
| --- | --- |
| [Review Bridge](projects/review-bridge.md) | Windows からペアリング済みの Android 端末へレビュー作業を送り、利用者が結果を PC に戻せる。 |
| [Pad Launcher](projects/pad-launcher.md) | Android のホーム画面と、AI 支援で振り分けられるインボックスを提供する。 |
| [BOOX Ink Notes](projects/boox-ink-notes.md) | Android で手書きの筆跡を取り込み、ノートを保存して再び開く。 |
| [XTEINK Text Converter](projects/xteink-text-converter.md) | テキストを含む PDF とプレーンテキストを、E Ink で読むための TXT に変換する。 |

[プロジェクト一覧](PROJECTS.md)と各紹介ページで、実装の内容と確認できた根拠を説明しています。

MemoMind One では、まずスマートフォンから短い文章を表示し、次にユーザーが求めた AI の要約や、選んだタスク・予定の表示へ広げたいと考えています。[MemoMind One 開発計画（英語）](MEMOMIND_DEVELOPMENT_PLAN.md)
