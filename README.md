# Independent software development portfolio

I build Android and Windows software in Kotlin and C#. My projects include a launcher with an AI-assisted inbox, a Windows-to-Android review workflow, and tools for reading and handwriting on E Ink devices. I use AI-assisted development tools and review the resulting changes against the behavior I want to deliver.

## Selected work

| Project | What it does |
| --- | --- |
| [Review Bridge](projects/review-bridge.md) | Moves a review task from Windows to a paired Android phone and lets the user send the result back. |
| [Pad Launcher](projects/pad-launcher.md) | Provides an Android home screen and an inbox with AI-assisted triage. |
| [BOOX Ink Notes](projects/boox-ink-notes.md) | Captures handwritten ink and lets users save and reopen notebook pages on Android. |
| [XTEINK Text Converter](projects/xteink-text-converter.md) | Converts text-based PDFs and plain text into TXT files for E Ink reading. |

The [project index](PROJECTS.md) summarizes the implementation and the available evidence for each project.
